# 0x00. C - File I/O

## Description

This project covers low-level file I/O in C, using the system calls
`open`, `close`, `read`, and `write` instead of the standard library's
buffered I/O functions.

By the end of this project, you should be able to explain:

- How to create, open, close, read and write files
- What file descriptors are
- What the 3 standard file descriptors are, their purpose, and their
  POSIX names
- How to use the I/O system calls `open`, `close`, `read` and `write`
- What the flags `O_RDONLY`, `O_WRONLY`, `O_RDWR` are and how to use them
- What file permissions are, and how to set them when creating a file
  with the `open` system call
- What a system call is
- The difference between a function and a system call
